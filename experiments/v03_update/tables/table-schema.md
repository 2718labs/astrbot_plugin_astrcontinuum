# Table schema / 表格数据契约

| Table | Purpose / 用途 | Rows / 行 | Metrics / 指标 | Data source / 数据来源 | Replacement owner / 更新责任 |
| --- | --- | --- | --- | --- | --- |
| Gate A receipt CSV | auditable per-unit worker wiring result / 可审计的逐单元接线结果 | 12 scenarios × 3 trials = 36 | committed status, pointer versions, ledger count/hash, retained/approximate/released counts, stable failure codes | `docs/evidence/v03-update-gate-a/receipt.csv` generated by `v03_update_benchmark.py` | admitted `V03-WIRE-001` execution |
| Gate A aggregate table | human-readable fixed-denominator summary / 人可读固定分母汇总 | one aggregate row | baseline/update commit, exact `1 → 2`, durable ledger, required core edges, non-summary releases | `docs/evidence/v03-update-gate-a/aggregate.csv` | deterministic aggregate from the admitted receipts |
| Gate B paired E2E table | v0.3 versus refreshed Summary / v0.3 对比重新生成的 Summary | 36 paired units | current-state QA pass, stale facts, unsupported claims, exact McNemar | approved raw Provider receipts + frozen scorer | BLOCKED owner: evaluator |

The Gate A table must keep failures in the denominator. `V03-WIRE-001` is a
structural wiring record, not a semantic score. Gate B must never be filled
with synthetic or planned values. Gate A 表必须把失败保留在分母中；
`V03-WIRE-001` 是结构接线记录，不是语义评分。Gate B 不得填入合成或规划数值。
