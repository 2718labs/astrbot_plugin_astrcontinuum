# AstrContinuum v0.2.1 Tokenizer and Auto Context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.2.1 on top of the released v0.2.0 baseline with offline model-aware token counting, `model_context_limit = 0` automatic AstrBot metadata resolution, request-atomic byte fallback, encrypted canonical Token metrics, and bounded final-projection verification.

**Architecture:** A read-only `TokenizerRegistry` owns verified local `o200k_base` and `cl100k_base` assets, while immutable request and compaction profiles select counters without mutable global model state. Existing Journal/Capsule/Snapshot compatibility counts remain UTF-8-byte logical values but move into AES-GCM envelopes; a separately encrypted canonical sidecar supplies stable segmentation metrics. Live budgeting performs one coarse-grained worker-thread run over one immutable request view, discards the whole primary run on tokenizer failure, and proves the final projection before touching AstrBot's request objects.

**Tech Stack:** Python 3.10–3.13, AstrBot 4.24.x–4.26.x public plugin APIs and Hook objects, `tiktoken>=0.12,<0.14`, AES-256-GCM via `cryptography`, SQLite WAL/CAS, Pydantic v2, NumPy/SciPy sparse context engine, pytest, uv, Ruff, mypy, GitHub Actions.

## Non-Negotiable Invariants

1. `EventEnvelope.token_count` and Capsule/Snapshot `token_cost` keep their v0.2.0 UTF-8-byte logical values and deterministic-ID behavior.
2. Those compatibility integers and all new exact Token metrics are physically AES-GCM encrypted in SQLite.
3. A request, compaction call, or canonical metric computation never mixes profiles.
4. Tokenizer work, asset loading, canonical rendering, and counting happen outside SQLite write transactions.
5. A tokenizer failure discards every primary-run count, selection, and projection, then reruns the same immutable workload wholly with `utf8-byte-v1`.
6. Required host content over budget, a too-small model window, or final verification failure leaves native AstrBot messages unchanged.
7. Segmenter receives complete `canonical-o200k-v1` metrics or defers with `TOKEN_METRIC_MISSING`; it never falls back to compatibility counts.
8. Logs, status, exceptions, `repr`, and persisted diagnostics contain no model name, Provider ID, message text, token pieces, asset path, or dynamic exception text.
9. No runtime tokenizer network access or tokenizer cache writes are permitted.

class TokenizerMode(str, Enum):
    CANONICAL = "CANONICAL"
    EXACT_TEXT = "EXACT_TEXT"
    REFERENCE = "REFERENCE"
    BYTE_FALLBACK = "BYTE_FALLBACK"


@dataclass(frozen=True, slots=True)
class TokenizerProfile:
    profile_id: str
    schema_version: int
    mode: TokenizerMode
    encoding_name: str | None
    implementation_name: str
    implementation_version: str
    asset_digest: str | None
    count_multiplier_basis_points: int


def apply_multiplier(raw_count: int, basis_points: int) -> int:
    if isinstance(raw_count, bool) or not isinstance(raw_count, int) or raw_count < 0:
        raise TokenizerError(TokenizerErrorCode.TOKENIZER_COUNT_INVALID)
    return (raw_count * basis_points + 9_999) // 10_000


@dataclass(frozen=True, slots=True)
class ProfileCounter:
    profile: TokenizerProfile
    _encoding: object = field(repr=False)

    def count_text(self, text: str) -> int:
        raw = len(self._encoding.encode_ordinary(text))
        return apply_multiplier(raw, self.profile.count_multiplier_basis_points)

    def count_texts(self, texts: Sequence[str]) -> tuple[int, ...]:
        return tuple(self.count_text(text) for text in texts)
```

def load_mergeable_ranks(path: Path, expected_digest: str) -> dict[bytes, int]:
    data = path.read_bytes()
    if not hmac.compare_digest(hashlib.sha256(data).hexdigest(), expected_digest):
        raise TokenizerError(TokenizerErrorCode.TOKENIZER_ASSET_INVALID)
    ranks: dict[bytes, int] = {}
    for line in data.splitlines():
        token_text, rank_text = line.split()
        token = base64.b64decode(token_text, validate=True)
        rank = int(rank_text)
        if token in ranks or rank < 0:
            raise TokenizerError(TokenizerErrorCode.TOKENIZER_ASSET_INVALID)
        ranks[token] = rank
    if len(set(ranks.values())) != len(ranks):
        raise TokenizerError(TokenizerErrorCode.TOKENIZER_ASSET_INVALID)
    return ranks
```

class ContextLimitSource(str, Enum):
    MANUAL = "MANUAL"
    AUTO_ASTRBOT = "AUTO_ASTRBOT"
    AUTO_SAFE_FALLBACK = "AUTO_SAFE_FALLBACK"


@dataclass(frozen=True, slots=True)
class ContextLimitDecision:
    limit: int
    source: ContextLimitSource
    stable_code: str


class ContextLimitResolver:
    def resolve(
        self,
        configured_limit: object,
        *,
        provider_limit: object = None,
        request_model: str | None = None,
        provider_model: str | None = None,
    ) -> ContextLimitDecision:
        if isinstance(configured_limit, bool) or not isinstance(configured_limit, int):
            return ContextLimitDecision(
                128_000,
                ContextLimitSource.AUTO_SAFE_FALLBACK,
                "CONTEXT_LIMIT_CONFIG_INVALID",
            )
        if configured_limit > 0:
            return ContextLimitDecision(
                configured_limit,
                ContextLimitSource.MANUAL,
                "NONE",
            )
        if configured_limit < 0:
            return ContextLimitDecision(
                128_000,
                ContextLimitSource.AUTO_SAFE_FALLBACK,
                "CONTEXT_LIMIT_CONFIG_INVALID",
            )
        if (
            isinstance(provider_limit, bool)
            or not isinstance(provider_limit, int)
            or provider_limit < 1
        ):
            return ContextLimitDecision(
                128_000,
                ContextLimitSource.AUTO_SAFE_FALLBACK,
                "CONTEXT_LIMIT_UNAVAILABLE",
            )
        request_name = normalize_model_identity(request_model)
        provider_name = normalize_model_identity(provider_model)
        if request_name is not None and request_name != provider_name:
            return ContextLimitDecision(
                min(provider_limit, 128_000),
                ContextLimitSource.AUTO_SAFE_FALLBACK,
                "CONTEXT_LIMIT_UNAVAILABLE",
            )
        return ContextLimitDecision(
            provider_limit,
            ContextLimitSource.AUTO_ASTRBOT,
            "NONE",
        )


@dataclass(frozen=True, slots=True, repr=False)
class RequestBudgetProfile:
    model_identity: str | None = field(repr=False)
    context_limit: int
    context_limit_source: ContextLimitSource
    tokenizer_profile: TokenizerProfile
    target_input_budget: int
    hard_input_ceiling: int
    reserved_output_and_tools: int = 32_000
    safety_margin: int = 2_000
    stable_code: str = "NONE"

    @property
    def effective_input_budget(self) -> int:
        return min(
            self.target_input_budget,
            self.hard_input_ceiling,
            self.context_limit - self.reserved_output_and_tools,
        )
