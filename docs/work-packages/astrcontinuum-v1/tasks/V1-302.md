## Runtime Contract

Keep projection core AstrBot-free. Use request-local immutable guard/projected/restored
DTOs and equivalent typed functions:

```python
def guard_projection(request: object, messages: list[object], *,
                     system_objects: tuple[object, ...],
                     current_objects: tuple[object, ...]) -> ProjectionGuard: ...
def project(messages: list[object], guard: ProjectionGuard,
            projection_objects: tuple[object, ...]) -> ProjectedView: ...
def restore(messages: list[object], projected: ProjectedView) -> RestoredView: ...
def verify_native(messages: list[object], restored: RestoredView) -> bool: ...
```

The guard records request identity, list identity, original native objects, native
history identities, and preserved system/current objects. At priority `-100`, remove
only native history objects still present after other begin Hooks, preserve every opaque
new object plus system/current objects by identity, and insert AC-owned temporary
projection objects immediately before the current turn. At done priority `2000`, restore
the exact pre-AC list plus the appended Delta:

```text
R_A(P_A(X) + Delta) = X + Delta
```

Restore only when request, list, preserved objects, and projected prefix identities all
match. A mismatch never guesses or rewrites by value. Errors and diagnostics expose
stable codes, stage, counts, and booleans only; never message text, tool payloads, model
errors, Sylanne data, or stable hashes of opaque objects.

The AstrBot adapter is the sole module allowed to capability-probe internal `Message` /
`TextPart` construction required by the frozen design. AC projection content must be a
temporary `TextPart`, its enclosing user message must be marked provider-only where the
verified host supports `_no_save`, and missing imports/attributes disable projection for
that request. Core runtime/storage/compaction modules import no `astrbot.core.*`.

`on_llm_request(priority=2000)` derives the exact seven-field `SessionKey`, performs
idempotent `capture_user_event` in `asyncio.to_thread`, reads one committed view, and
stores only request-local prepared AC data in a private namespaced event-extra key. It
never mutates `req.contexts`, waits for compaction, calls a model, or reads Sylanne.

Use two `on_agent_begin` handlers: priority `2000` records the native identity guard;
priority `-100` counts preserved non-owned objects ephemerally, calls the existing
fallback retrieval/budget assembly once, builds the temporary projection, and projects
in place. Use two `on_agent_done` handlers: priority `2000` restores AC projection;
priority `900` verifies native restoration, captures the authoritative assistant event
once, and raises only the bounded durable compaction intent. `on_llm_response` remains
observational and writes nothing.

`on_using_llm_tool` and `on_llm_tool_respond` are the only tool Journal writers. Encode
bounded canonical tool metadata until V1-501 owns external payload bytes. Stable
idempotency/event identities derive from host message identity, Hook, deterministic
per-turn tool ordinal, and canonical metadata; process time, random UUIDs, Python hash,
and content-dependent log messages are forbidden. Missing stable host identity skips the
durable write and records a redacted fault rather than merging events.
