uv run --extra dev pytest tests/contracts/test_capsule_contract.py -q
uv run --extra dev pytest tests/contracts/test_persistence_contract.py -q

Pass conditions:

- each focused suite has a saved intended RED predating its corresponding contract edit;
- all Capsule and nested objects are closed and use full SessionKey identity;
- structured Master Prompt fields and source ids remain authoritative over narrative;
- `capsules` and ordered `snapshot_capsules` are immutable and same-session;
- candidate Capsules, membership, and Snapshot share one savepoint and all roll back on
  CAS loss;
- old runtime tests remain green;
- production Python, metadata, and release version are unchanged.

Strict completion additionally requires output index sync/query without miss escape and a
verification artifact bound to the output snapshot.
