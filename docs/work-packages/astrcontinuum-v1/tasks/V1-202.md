## Steps

1. Run the unchanged full suite and record the 34-test baseline.
2. Create only `test_sqlite_connection_policy.py`. Import the existing top-level package
   and assert the missing factory export so RED is behavioral, not an import error.
3. Confirm RED for file placement, WAL mode, per-connection foreign keys, bounded busy
   timeout, explicit transaction commit/rollback, and read-only enforcement.
4. Add the minimal connection factory with manual transactions, `sqlite3.Row`, default
   100 ms busy timeout, and a database file owned by the supplied data directory.
5. Run the connection suite green.
6. Create only `test_sqlite_migrations.py`; confirm missing migration behavior RED.
7. Add a packaged Python migration ledger and checksum-verified runner. Migration 1
   creates `sessions`, `journal_events`, `capsules`, `snapshots`,
   `snapshot_capsules`, `active_snapshots`, `compaction_jobs`, required indexes,
   cross-field checks, and immutability triggers.
8. Prove migration reruns are idempotent, concurrent initializers converge, checksum
   drift is rejected, and a failed injected migration rolls back both DDL and ledger.
9. Parse frozen Schemas; run focused storage tests, all existing tests, focused lint,
   full diagnostic lint, type checking, and DevKit validators.
10. Complete the strict output-index query and evidence gate without miss escape.

starter import-format findings remain outside this exact card; no new finding may appear.

Pass conditions:

- every writable connection has `journal_mode=wal`, `foreign_keys=1`, manual transaction
  control, row access by name, and a finite configured busy timeout;
- read-only connections cannot mutate, and transaction exceptions roll back completely;
- migration 1 matches the frozen relational contract and rejects invalid identity,
  event triples, job conditions, broken foreign keys, and immutable-row updates/deletes;
- migration application is atomic, ordered, checksum verified, idempotent, and safe
  under multiple initializer connections;
- no repository transaction, AstrBot Hook, compiler, auditor, `main.py`, user database,
  wire Schema, dependency declaration, metadata, or release version is changed;
- all V1-202 files pass focused lint/format, all source files pass mypy, and the full
  pytest suite remains green.

Strict completion additionally requires output index sync/query without miss escape and a
verification artifact bound to the output snapshot.
