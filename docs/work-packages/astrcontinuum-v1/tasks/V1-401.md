## Runtime Contract

Use immutable DTOs and equivalent typed signatures:

```python
class SegmentBoundaryReason(str, Enum): ...
@dataclass(frozen=True, slots=True)
class SegmenterConfig:
    max_events_per_segment: int = 16
    max_tokens_per_segment: int = 4096
    max_preferred_boundaries: int = 128
@dataclass(frozen=True, slots=True)
class EventSegment:
    start_sequence: int
    end_sequence: int
    events: tuple[EventEnvelope, ...]
    token_cost: int
    boundary_reason: SegmentBoundaryReason
def segment(events: Sequence[EventEnvelope], *, config: SegmenterConfig,
            preferred_end_sequences: Sequence[int] = ()) -> tuple[EventSegment, ...]: ...
```

Accept one non-empty, single-session, strictly contiguous sequence. Preserve every
event once in order. Bound/deduplicate/sort preferred boundaries and ignore out-of-range
values. Do not split an adjacent tool-call/result pair for a soft boundary. Hard limits
may isolate one oversized event but never truncate/drop content.

```python
@dataclass(frozen=True, slots=True)
class CompilationRequest:
    base_snapshot: SnapshotEnvelope | None
    base_capsules: tuple[ContextCapsuleEnvelope, ...]
    source_events: tuple[EventEnvelope, ...]
    segments: tuple[EventSegment, ...]
    target_high_water_mark: int
    token_ceiling: int
@dataclass(frozen=True, slots=True)
class CompilerOutput:
    capsules: tuple[ContextCapsuleEnvelope, ...]
    rendered_context: str
class CompilerBackend(Protocol):
    async def compile(self, request: CompilationRequest) -> CompilerOutput: ...
@dataclass(frozen=True, slots=True)
class CompilationCandidate:
    snapshot: SnapshotEnvelope
    memberships: tuple[SnapshotCapsuleMembership, ...]
    segments: tuple[EventSegment, ...]
    permanent_report: PermanentValidationReport
async def compile_candidate(*, base_snapshot, base_capsules, source_events,
    target_high_water_mark, token_ceiling, backend, counter: TokenCounter,
    now: datetime, segmenter_config, preferred_end_sequences=()) -> CompilationCandidate: ...
```

Validate complete base/Delta locally, then call the backend exactly once. Its output is
the complete candidate, not a patch. Preserve Capsule order as membership ordinals;
derive active anchor ids; count rendered context exactly through the injected
non-negative counter. Build stable Snapshot identity from SHA-256 of canonical AC-owned
schema/session/base/target/Capsule/anchor/rendered-context/cost data. Random UUIDs,
process time, Python hash, and opaque third-party content are forbidden.

Errors contain stable codes/mechanical failure codes only, never Event/Capsule text or
backend exception messages. The backend sees AC-owned base/Journal data and no
Sylanne/private external-memory payload.

`validate_candidate(...) -> PermanentValidationReport` delegates to
`domain.validate_permanent` exactly once with no bypass. A prior active semantic may
remain active or become superseded/retracted only when the same stable id remains and
the transition cites a current-Delta source. Removing it still yields
`MISSING_PRIOR_SEMANTIC`. Prior active exact anchors remain active/exact. Every existing
identity, gap, target, source, quality, non-empty, anchor, and token gate stays permanent.

```python
@dataclass(frozen=True, slots=True)
class SemanticAuditReport:
    passed: bool
    failure_codes: tuple[str, ...]
class SemanticAuditBackend(Protocol):
    async def audit(self, request: SemanticAuditRequest) -> SemanticAuditReport: ...
async def audit_semantic(candidate: CompilationCandidate, *, strict_audit: bool,
                         backend: SemanticAuditBackend | None) -> AuditedCandidate: ...
```

Mechanical validation precedes every branch. Disabled audit makes zero backend calls and
keeps `NOT_RUN`; enabled audit calls once and produces `PASSED`/`FAILED`. Invalid output
or exceptions reject with unique deterministic content-free codes. Failure can never
enter publication.
