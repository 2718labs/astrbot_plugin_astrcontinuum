## v0.3.0 Technical Preview — 当前集成基线

本里程碑以已验证的 **v0.2.1** 运行时为基础，叠加范围受限的 **v0.3.0** 持久化安全契约。
保留的运行时基线包括：

- 认证静态加密、密钥创建、轮换、恢复与事务化升级；
- 固定的离线 **cl100k_base** 与 **o200k_base** 资产，以及请求级 BYTE 回退；
- 相互独立的规范、实时请求与后台压缩 token 轨道，以及加密指标 sidecar 和有界补齐；
- 基于 AstrBot 公开 Provider 元数据的上下文窗口解析与保守自动兜底；
- 不含正文的状态与检查证据；
- 确定性、严格 allowlist、**<16 MiB** 的归档契约，以及历史 AstrBot **4.24.0** 与
  **4.26.7** 探针；其中当前 `metadata.yaml` 下限仍是 **>=4.24.2**，历史 4.24.0 不构成
  现行兼容承诺；以及
- 已接线的 worker 生命周期：领取、续租、重试、取消和 Snapshot 原子发布。

**v0.3.0** 在显式 Repository 发布边界新增 migration v3 与不可变、有序的重组账本存储。
永久质量闸门会拒绝任何非 **narrative_summary** 的 **released** 账本记录。这项能力有意保持
为 **storage-only**：标准 **CompactionWorker** 不调用重组器，也不提供记录，因此普通后台
压缩继续发布空账本。本里程碑不宣称重组执行、语义质量、Provider 性能、完整 AstrBot
兼容性或面向最终用户的公开发布就绪。

本 Technical Preview 的评测方案、冻结证据摘要和当前/目标工作流见
[评测](./EVALUATION.zh-CN.md)、[证据](./EVIDENCE.zh-CN.md) 与 [工作流](./WORKFLOW.zh-CN.md)。其中隔离的
合成与确定性记录不能构成生产语义质量、Provider 性能或公开发布就绪证据。

## v0.3.x — 接线与运维证据

- 只有在具备明确 source-item 记账、永久质量校验和聚焦回归证据后，才把重组器接入 worker。
- 在真实部署中验证已接线 worker、lease 续租、有界取消、加密升级、备份恢复、崩溃恢复和
  长时间 WAL 行为。
- 评估可选的语义审计 Provider，同时确保在线 Hook 始终不等待。
- 提供有界的重试、取消和安全回滚管理能力。
- 取得平台专项证据后，只声明真实验证过的适配器。
- 在不暴露 Provider 密钥或消息正文的前提下扩展多版本与长上下文探针自动化。

## v1.0 — 生产契约

- 稳定迁移与明确的升级、回滚策略。
- 在负载下证明非阻塞行为、崩溃原子性与跨会话隔离。
- 带来源追踪的多分辨率上下文重构。
- 使用显式 tokenizer profile 的可复现多 Provider 长上下文评测。
- 面向运维的备份、保留、隐私与恢复控制。
- 仓库、安全、文档与兼容门槛全部通过后，才提交 AstrBot 市场。

## 后续探索

- 混合检索与工具产物存储。
- 用户可编辑上下文策略。
- 具有明确权威边界的跨会话项目上下文。
- 多 Agent 上下文交换。
- 仅在保留确定性回退的前提下探索学习型选择器或专用 Context Codec。
