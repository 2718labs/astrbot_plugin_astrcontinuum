# 路线图

[English](./ROADMAP.md) | 简体中文

路线图只表达方向，不构成兼容承诺。具体提交的成熟度必须以 README、架构文档、Changelog
和验证证据为准。

## v0.2.1 — 已验证发布基线

仓库当前已经包含：

- 认证静态加密、密钥创建/轮换/恢复与事务化升级；
- 固定的离线 `cl100k_base`/`o200k_base` 资产和请求级 BYTE 回退；
- 相互独立的规范、实时请求与后台归约 token 轨道，以及加密 sidecar 和有界补齐；
- 基于 AstrBot 公开 Provider 元数据的窗口解析与保守自动兜底；
- 不含正文的状态/检查证据；
- 确定性、严格 allowlist、`<16 MiB` 的归档契约，以及真实 AstrBot
  `4.24.0`/`4.26.7` 探针。

可从仓库或已验证的发布 ZIP 安装。AstrBot 市场分发是独立维护者流程，本仓库 CI 不会执行。

## 后续 v0.2.x — 运维证据

- 在真实部署验证已接入 worker、续租、有界取消、加密升级、备份恢复、崩溃恢复和长期
  WAL 行为。
- 评估可选语义审计 Provider，且始终确保在线 Hook 不等待。
- 提供有界的重试、取消和安全回滚管理能力。
- 取得平台专项证据后，只声明真实验证过的适配器。
- 在不暴露 Provider 密钥或消息正文的前提下扩展多版本与长上下文探针。

## v1.0 — 生产契约

- 稳定迁移与明确升级/回滚规则。
- 在负载下证明非阻塞、崩溃原子性和跨会话隔离。
- 带来源追踪的多分辨率上下文重构。
- 使用显式 tokenizer profile 的可复现多 Provider 长上下文评测。
- 面向运维的备份、保留、隐私和恢复控制。
- 仓库、安全、文档与兼容门槛全部通过后，才提交 AstrBot 市场。

## 后续探索

- 混合检索与工具产物存储。
- 用户可编辑上下文策略。
- 具有明确权威边界的跨会话项目上下文。
- 多 Agent 上下文交换。
- 在保留确定性回退的前提下探索学习型选择器或专用 Context Codec。
