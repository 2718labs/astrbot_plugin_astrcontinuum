# 路线图

[English](./ROADMAP.md) | 简体中文

路线图只表达方向，不构成兼容承诺。具体提交的成熟度必须以 README、架构文档、Changelog
和验证证据为准。

## v0.1.x — 仓库稳定化

- 积累真实 AstrBot 与适配器兼容证据。
- 把后台压缩 worker 接入 `Star` 启动/终止，并实现有界取消。
- 选择生产编译/审计 Provider，确保在线 Hook 不等待。
- 增加 Provider tokenizer，同时保留保守安全预算。
- 提供队列深度、覆盖、重试、租约和降级码等运维指标。
- 在真实部署验证升级、备份恢复、崩溃与长期 WAL 行为。
- 在稳定化门槛明确通过前，只做仓库迭代。

## v0.2 — 受控压缩预览

- 通过显式配置开关启用自动领取 job。
- 提供有界的状态、重试、取消和安全回滚管理能力。
- 取得平台专项证据后，只声明真实验证过的适配器。
- 扩展多版本实机探针，且不暴露 Provider 密钥。
- 增加安全上下文检查器，区分来源证据与私密消息正文。

## v1.0 — 生产契约

- 稳定迁移与明确升级/回滚规则。
- 在负载下证明非阻塞、崩溃原子性和跨会话隔离。
- 带来源追踪的多分辨率上下文重构。
- Provider-aware 预算与可复现长上下文评测。
- 面向运维的备份、保留、隐私和恢复控制。
- 仓库、安全、文档与兼容门槛全部通过后，才提交 AstrBot 市场。

## 后续探索

- 混合检索与工具产物存储。
- 用户可编辑上下文策略。
- 具有明确权威边界的跨会话项目上下文。
- 多 Agent 上下文交换。
- 在保留确定性回退的前提下探索学习型选择器或专用 Context Codec。
